# SOP 08 — No TikTok Playbook

You do **not** need TikTok to earn with ClipCut + Content Rewards.

## Platforms that pay (campaign-dependent)
| Platform | Typical acceptance | Best for |
|----------|--------------------|----------|
| **YouTube Shorts** | High (often listed) | Best default without TikTok |
| **Instagram Reels** | Very high | Second default |
| **X (Twitter)** | Lower volume of campaigns | Extra if allowed |
| TikTok | Most campaigns | Optional later |

Sample market snapshot (Oct 2026 research): many campaigns accept IG + YT; TikTok is common but not universal.

## Manager rule
**Only join campaigns that list YouTube and/or Instagram.**  
Skip TikTok-only campaigns.

## Setup (15 min)
1. **YouTube** — create/use channel → enable Shorts uploads  
2. **Instagram** (optional but strong) — create/use account for Reels  
3. **Whop / Content Rewards** — connect YT + IG in account settings  
4. **ClipCut** — link YT / IG for bonus credits  
5. Extension Settings → Default account = `Main_YouTube_Shorts`

## Daily flow (no TikTok)
1. Filter campaigns: platforms include **YouTube** or **Instagram**
2. ClipCut → vertical 9:16 clips, score ≥ 72
3. Post **YouTube Short** first (or Reels if campaign prefers)
4. Submit post URL in campaign dashboard
5. Log in extension: Platform = YouTube or Instagram

## Caption note
Same hooks; always paste **exact campaign hashtags/CTA** from the brief.

## Later
If you create TikTok later, add it as a second account — do not block earning until then.
