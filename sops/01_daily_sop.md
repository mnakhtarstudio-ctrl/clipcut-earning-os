# SOP 01 — Daily Operating Procedure (45–90 min)

**Time blocks (IST recommended)**

### 08:30 – Research Intake (10 min)
- Read Daily Research Agent report
- Scan Whop Discover for new high-budget / high-CPM campaigns
- Score them with `tools/campaign_scorecard.md` or script

### 08:45 – Source Selection (5 min)
- Pick 2–4 authorized long videos from active campaigns
- Prefer talking-head, high-energy, clear audio (ClipCut loves these)

### 08:50 – Production Block (25–40 min)
1. Paste URLs into ClipCut (batch)
2. Wait for scores
3. Keep only clips ≥ 72 viral score (or top 40%)
4. Apply caption template from `templates/caption_library.md`
5. Download 1080p / 4K
6. Optional 30-sec CapCut polish only if campaign requires unique style

### 09:30 – Distribution Block (15–20 min)
- Post on primary TikTok first
- Cross-post to Reels / Shorts / X within 60–90 min
- Use exact hashtags + CTA from campaign brief
- Max 3–4 posts per account per day (avoid spam flags)

### 09:50 – Submission & Logging (5 min)
- Submit every link to Whop campaign dashboard
- Update `data/earnings_tracker.csv` (Date, Campaign, Score, Link, Status, Views, Est.Net)

### Evening (5 min)
- Check new views / approvals
- Note winning hooks for tomorrow

**Daily volume target by stage**
- Beginner: 5–8 clips
- Intermediate: 10–15 clips
- Scaled: 20+ across accounts
