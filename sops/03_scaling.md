# SOP 03 — Scaling Playbook (Multi-Account → Mini-Agency)

## Stage 1: Single Account Mastery ($500–1.5k/mo)
- 1 strong TikTok + 1 IG + 1 YT
- Perfect Daily SOP
- ClipCut Creator or Clipper plan

## Stage 2: Multi-Account (target $2–5k/mo)
Rules:
- Separate devices / browsers / IPs when possible
- Different posting times and slight caption variations
- Never post identical clips on same platform same day from different accounts
- Warm new accounts with 5–7 original posts first
- Track each account separately in the CSV (add Account column)

## Stage 3: Systems Operator
- Hire VA for posting only (you keep ClipCut + campaign selection)
- Create brand kits / style packs if campaigns allow
- Move into higher CPM niches (Finance, Tech, Education, Crypto)
- Start direct brand deals once you have proof (screenshots of payouts)

## Stage 4: Mini-Agency
- 3–5 clippers under you
- You provide sources + ClipCut access + quality control
- Take 30–50% of net
- Use shared Google Sheet + this system as the playbook

**Risk controls at every stage**
- No bots / fake engagement
- Strict campaign rule compliance
- Diversify across 4–6 campaigns so one dying budget doesn’t kill income
