# 02 — Daily / Weekly Workflow (Optimized for ClipCut)

**Time target**: 45–90 minutes/day for 5–10 clips → scalable to $2k+/mo.

## Morning / Start of Session (10 min)
1. Open Whop Content Rewards → scan new / high-budget campaigns.
2. Check your Research Agent report (daily automation) for hot niches, rate changes, new tools.
3. Review previous posts: views, approvals, rejections → note what hooks worked.

## Clipping Block (30–60 min) — The Money Machine
1. Select 1–3 authorized long videos (podcasts, streams, interviews preferred for talking-head virality).
2. Paste YouTube URL (or upload) into ClipCut.
3. AI returns 5–15 clips with virality scores (0–100), captions, 9:16 format.
4. Filter: Keep score ≥ 70–75 first. Prefer strong hook in first 1–3 seconds.
5. Quick review: Fix caption typos if any, add campaign-required hashtags/CTA in description (not always on video).
6. Download batch (1080p or 4K on Pro).
7. Optional: Light CapCut polish only if campaign demands unique style (most don't).

**ClipCut speed**: 1 min source ≈ 1 credit. 60-min podcast → ~10 clips in 3 min.

## Posting Block (15–20 min)
- Post to TikTok first (highest volume).
- Then cross-post to Reels / Shorts / X within 1–2 hours (or schedule).
- Use same caption template + campaign keywords + 3–5 hashtags.
- Post 1–3 times/day max per account to avoid spam flags. Use multiple accounts if scaling (separate devices or careful).

## Submission & Tracking (5 min)
- Immediately submit every post link to the campaign dashboard.
- Log in tracker: date, campaign, clip title, score, platforms, link, status (pending/approved), views, estimated earnings.

## Evening Review (5 min)
- Check approvals & view counts.
- Withdraw when balance hits min (usually $20–50).
- Note best performing clips → reverse engineer hooks for tomorrow.

## Weekly Optimization
- Upgrade ClipCut plan if processing >200 credits/mo.
- Rotate niches if one dries up (crypto high CPM but competitive; gaming high volume lower CPM).
- Test 2–3 caption styles / hook formats.
- Scale: Add second account or hire VA for posting only.

## Scaling Math
- 8 clips/day × 20k avg views × $1.25/1K = ~$200/day potential (before caps & competition).
- Reality: 30–50% of clips get decent views; focus volume + selection.
