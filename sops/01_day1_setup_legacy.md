# 01 — Setup Guide (Complete in < 2 Hours)

## Day 1 Checklist

### 1. Accounts (Free First)
- [ ] **Whop**: https://whop.com → Sign up (Google or email). Browse "Content Rewards" or search "clipping".
- [ ] **ClipCut**: https://www.clipcut.pro → Start free trial (30 credits, no card). Link TikTok/IG/YT/X/Discord for +5 credits each (max +25).
- [ ] Social accounts: Create or use existing **TikTok** (primary for views), Instagram, YouTube Shorts, X. Warm them up with 5–10 original posts if brand new.

### 2. Link Everything
- In Whop: Connect your social accounts so views can be verified.
- In ClipCut: Link same channels for free credits.

### 3. Pick First Campaigns
Look for free-to-join campaigns with:
- Rate ≥ $1.00 / 1K views
- Remaining budget > $1,000
- Low min-view threshold (1K–5K ideal)
- Clear source content provided (YouTube links or downloads)
- Allowed platforms: TikTok + at least one more

Popular entry points (as of late 2026 research): ClipIt, Pack Rush Clipping, streamer/gaming, podcast, motivation, crypto (higher pay but stricter).

**Pro tip**: Never pay for "clipping courses" or access — biggest free campaigns have 10k–100k members and pay.

### 4. Tools Setup
- ClipCut plan: Start with free trial. Upgrade to Creator ($9/mo annual) once you post 5+ clips.
- Browser folders: "Sources", "Ready Clips", "Submitted".
- Phone apps: TikTok, CapCut (backup manual edits), Whop app if available.

### 5. Legal / Safety
- Only clip content authorized by the campaign.
- Follow exact hashtags, captions, CTAs, no watermarks, length limits.
- No botting / fake views — Whop detects and bans.
- Disclose if required (rare for pure clipping).

### 6. First Clip Test
1. Join one campaign → get source YouTube URL.
2. Paste into ClipCut → wait 2–5 min.
3. Download top 3–5 clips (score >70 preferred).
4. Post on TikTok (best time usually 6–9pm local or check analytics).
5. Submit post link + any required file in Whop.
6. Wait for approval (often 24–72h).

Done. You are live.
